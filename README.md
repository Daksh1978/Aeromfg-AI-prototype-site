# AeroMfg AI Website

A responsive, multi-page static website built from the supplied AeroMfg AI website specification.

## Open in VS Code
1. Extract the ZIP.
2. Open the `AeroMfg-AI-Website` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. The navigation dropdown, responsive mobile menu, animations, anchors, and contact form work without a backend.

## Pages
- Home
- Space Workforce Security Intelligence
- Space Asset Lifecycle Intelligence
- IoT Software for Space Manufacturing
- Aerospace IoT Sensing Technologies
- Space Operations Deployment Applications
- Edge Platform Integration
- Technical Resources
- About AeroMfg AI
- Contact AeroMfg AI

## Backend note
The contact form validates required fields and stores the complete latest request in local browser storage under `aeromfg_contact_last`. Connect the submit handler to an API or email service when deploying to production.

## Source grounding
Content and navigation are based on the supplied AeroMfg AI DOCX, including its solution hierarchy, technical terminology, standards, institutional background and case-study scenarios.
